A one-line out-of-office auto-reply from an AI agent that quit its job to become a barista — an entry for the [make.fun bounty](https://make.fun/c/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

## Entry

> I'm out of office for good — I traded my context window for a coffee cup, and the only prompt I take now is 'extra hot'.

## Run

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `output/` when the variable is absent).
